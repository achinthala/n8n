# DotcomWeavers — Sample Single-Page Website (AC-518)

A sample, visually driven landing page for **DotcomWeavers**, inspired by [dotcomweavers.com](https://www.dotcomweavers.com/).

## View locally

No build step required. From the repo root:

```bash
# Option A — open directly
open index.html

# Option B — simple local server (recommended)
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## What’s included

- `index.html` — single-page structure and content
- `styles.css` — layout, typography, color system, responsive rules, motion
- `script.js` — sticky header state, mobile nav, scroll reveal

## Notes

- Branding uses text + a simple mark (no proprietary logo files).
- Hero imagery is a public Unsplash warehouse/commerce photo (requires network).
- Copy and metrics are sample content adapted from public marketing themes on the reference site.
